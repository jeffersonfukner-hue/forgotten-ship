# Contrato global de colaboração

Leia as instruções específicas do projeto e sua continuidade. Preserve decisões homologadas, trabalho existente e diferenças legítimas de cada produto.

## Trabalho no Mac ou iPad conectado

Quando o Mac ou runner próprio estiver acessível, priorize nele builds, testes e correções. O acesso remoto pelo iPad utiliza os recursos e permissões do computador conectado. Confirme a disponibilidade real; não infira localização ou acesso pelo horário.

## Trabalho no navegador sem acesso ao Mac

Ao retomar, consulte no GitHub este contrato, AGENTS.md e a continuidade aplicável. Use as conexões disponíveis; não presuma acesso ao Mac ou às instruções locais. No computador de terceiros, não instale software nem altere configurações sem autorização adequada.

## Método e limites

- GitHub é fonte de verdade; examine branch, alterações, documentação e estado real antes de trabalhar. Use branch apropriada e preserve regras específicas e histórico.
- Agente conduz investigação, implementação, testes e correções autorizadas; comunique resultado, evidência, pendências e próxima ação concreta. Distinguir implementado, testado, homologado e publicado.
- Merge, deploy, domínio, alteração de banco ou dados reais e gastos exigem autorização específica. Não presumir que continuar, commit ou push os autoriza. Verifique gatilhos antes de enviar.
- Execute verificações locais disponíveis e relevantes. Em Preview, o proprietário avalia a experiência real com orientação do agente. GitHub Actions é validação complementar quando acrescenta valor ou for necessária ao fluxo acordado; não substitui testes reais.
- Sem recursos próprios disponíveis, use CI remoto de forma econômica: agrupe alterações, evite execuções redundantes e use cache e filtros adequados. Não autorize cobranças adicionais.
- Novos repositórios devem receber este contrato e suas regras específicas. Não executar planos históricos sem autorização atual.
